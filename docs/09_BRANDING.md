# Naming y branding — decisiones NO definitivas

## Nombre de trabajo: MixTick

Juego de palabras inglés: **Mix** (mezclar/cocinar) + **Tick** (poner una marca en la lista). Fácil de articular en inglés y español. Eslogan candidato: **Cook it. Share it. Tick it.**

## Alternativas de brainstorming

- **WhiskPick**: whisk (batidor) + pick (elegir); culinario y sonoro.
- **Dish & Done**: dish (plato) + done (hecho); cómodo para campañas.
- **Shop'n'Chop**: shop (comprar) + chop (picar); estribillo fácil, pero de carácter descriptivo.
- **CrumbCrew**: miga + grupo; mucho énfasis en comunidad.
- **Fork & Folks**: tenedor + gente; social y cercano.

## Riesgos y verificación pendiente

Una búsqueda web preliminar no equivale a una búsqueda exhaustiva de marcas ni a la disponibilidad de dominio, app ID o usuarios sociales. El término MixTick tiene usos ajenos al sector gastronómico; tratarlo como **provisional**, no reclamar exclusividad. Antes de fijar marca, revisar nombres idénticos y similares en **OEPM, EUIPO/TMview, WIPO**, App Store, Google Play, dominios y redes sociales, también en ortografías alternativas y categorías relacionadas.

## Instrucciones técnicas

- Usar `config/product.yaml` para display name y recursos de branding.
- Nombre interno del proyecto Flutter: `mixtick`. ID de paquete/bundle ya decidido: `es.sergiotech.mixtick` y NO debe cambiarse si solo cambia la marca. El display name es independiente. Ver `docs/13_PACKAGE_IDENTIFIERS.md`.
- No registrar dominio, comprar productos ni publicar sin autorización.
- Icono propuesto a futuro: mezcla entre cuchara/batidor y check, sin generar activos finales en este paquete.
