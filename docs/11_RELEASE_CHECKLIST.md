# Puerta de calidad antes de publicar (no autoriza el despliegue)

- [ ] 4 módulos completos con flujos reales, no datos simulados.
- [ ] Tests de lógica + widgets + integración ejecutados; valores reales documentados.
- [ ] RLS de todas las tablas y Storage probada con diferentes usuarios.
- [ ] Ninguna service_role ni secreto en app o Git.
- [ ] Política de privacidad y condiciones adecuadas, accesibles y revisadas.
- [ ] Eliminación de cuenta, petición de datos y gestión de incidencias implementadas según requisitos aplicables.
- [ ] Denunciar y bloquear usuarios/contenido; moderación mínima disponible.
- [ ] Formulario de fichas App Store / Play Store, clasificaciones, declaraciones de datos y permisos preparados y verificados con guías vigentes.
- [ ] Test real Android; test real iOS cuando se disponga del entorno de firma/compilación.
- [ ] Revisión de costes y limitaciones de Supabase Storage/Realtime; no asumir plan gratuito ilimitado.
- [ ] Nombre comercial validado legalmente/comercialmente; dominio, IDs, soporte y branding preparados.
- [ ] Instrumentación mínima para fallos respetando privacidad; copias de seguridad y restauración planeadas.
- [ ] Aprobación explícita del propietario antes de publicar, commit, push o despliegue.
